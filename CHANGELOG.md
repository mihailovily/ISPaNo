# Changelog

## 0.2.0

- Добавлены защищённый web-интерфейс и последовательная очередь заданий для JSON-экспортов и XLSX-отчётов.
- JSON v2 стал каноническим форматом: timestamped-экспорт и `exports/latest.json` записываются атомарно.
- Добавлены XLSX-отчёт по заявкам, локальные справочники алиасов и опциональная AI-суммаризация через OpenAI-совместимый endpoint или GigaChat.
- Добавлен Telegram-бот с allowlist пользователей, который формирует JSON v2 без записи выгрузки на диск.
- Введены `src`-layout, единая валидация конфигурации, Docker Compose profiles и CI-проверки.
