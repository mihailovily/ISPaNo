Обоснование

Внутри отдела ТСиТП возникла необходимость в локальной ии-модели достаточно крупного размера. Появление модели необходимо для дальнейшего развития проекта по генерации автоматизированных отчетов о состоянии тикетов. По результам тестов внутри отдела стала ясна необходимость в модели, по параметрам сходной с claude-sonnet-4-6. Таковой моделью является Qwen3.8-27B. В то же время Qwen3.8-Flash-Next первосходит требуемые показатели и является более перспективным вариантом.
Возможно, допустимо использование модели меньшего размера, но данный факт невозможно подтвердить без тестов.
Аппаратно для запуска Qwen3.8-27B следует иметь NVIDIA с 32 ГБ VRAM (RTX 5090) и от 64 ГБ RAM. Для Ternary Bonsai 2 27B необходжима видеокарта с 16 ГБ видеопамяти и 32–64 ГБ RAM (RTX 5070 Ti, RTX 4090)


1. Ожидаемый результат

На сервере развернут работающий API-endpoint, совместимый с форматом OpenAI, и моделью, содержащей не менее 27 млрд параметров. Для развертывания допустимо использовать llama.cpp или LM Studio


Целевые условия:
• Текстовый вход — до 16 000 токенов с запасом не менее 512 токенов на ответ.
• Поддержка 1–2 одновременных запросов.
• Полный ответ на запрос — не более 60 секунд при заранее загруженной модели.

3. API и доступ

Адрес API: https://x.x.x.x/v1. API должен использовать формат OpenAI.

Авторизация: Authorization: Bearer <token>. 

Модель: необходимо передать название выбранной модели и её идентификатор для запросов.

Метод POST /v1/chat/completions должен принимать:
• Текстовые сообщения с ролями system, user и assistant.
• Поле model
• Параметры stream и max_tokens.

При stream: false ответ должен содержать непустой текст в choices[0].message.content.

При stream: true должны выдаваться совместимые SSE-фрагменты с завершением потока.

По умолчанию должен быть выбран быстрый режим без длинного рассуждения.

Пример запроса для проверки:

curl -X POST "https://x.x.x.x/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"model":"local-chat","messages":[{"role":"system","content":"Ответь по-русски одним предложением."},{"role":"user","content":"Сколько будет 2 + 2?"}],"stream":false,"max_tokens":128}'
