# Техническое задание: selfhosted LLM endpoint

## 1. Результат

На сервере развернуть работающий текстовый OpenAI-совместимый API с моделью, содержащей **не менее 27B параметров**.

Требуется endpoint и результаты испытаний.

Целевые условия: текстовый вход до **32 000 токенов** с запасом не менее 512 токенов на ответ; **1–2 одновременных коротких запроса**; полный ответ на короткий запрос не дольше **60 секунд** при заранее загруженной модели. Для запроса на 32 000 токенов время измеряется и включается в итоговый отчет о проделанной работе

Порядок решения:

1. Если Flash-Next заведомо не помещается в доступную память с запасом под контекст и движок, не тестировать её;
2. Испытать Qwen3.8-27B `Q4_K_M` как базовую модель.
3. Если Flash-Next и Qwen3.8-27B не проходят требования, испытать Bonsai 2.
4. Если ни один вариант не проходит критерии, передать конфигурации сервера с целью согласования размеров модели.

## 3. API и доступ

- Внешний адрес: `https://192.168.x.x/v1`. Эндпоинт должен использовать формат OpenAI
- Авторизация: `Authorization: Bearer <token>`. Токен передать
- Модель: передать выбранное и используемое для запросовтназвание модели
- `POST /v1/chat/completions` принимает текстовые сообщения с ролями `system`, `user`, `assistant`, поле `model: "local-chat"`, параметры `stream` и `max_tokens`. При `stream: false` ответ содержит непустой текст в `choices[0].message.content`; при `stream: true` выдаются совместимые SSE-фрагменты с завершением потока.
- По умолчанию выбран быстрый режим без длинного рассуждения.

Пример запроса для проверки (подставить выданный внутренний адрес и токен):

```bash
curl -X POST "https://<внутренний-dns>/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"model":"local-chat","messages":[{"role":"system","content":"Ответь по-русски одним предложением."},{"role":"user","content":"Сколько будет 2 + 2?"}],"stream":false,"max_tokens":128}'
```
